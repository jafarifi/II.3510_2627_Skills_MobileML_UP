# SwapCampus — Mobile ML exercise

Version à compléter pour la présentation de Jade Sakly et Ange Nolwen Djuissi K.

Ouvrir ce dossier dans Android Studio, puis lancer le module `app` sur un téléphone ou un émulateur Android (API 24 minimum). Le SDK de compilation est 37. Android Studio configure le chemin du SDK dans `local.properties`.

Lire [EXERCISE.md](EXERCISE.md) pour les quatre TODO et les vérifications. Les images d’essai se trouvent dans `demo/`. Le support de présentation est `Presentation_MobileML.pptx`.

Cette version compile, mais les deux fonctionnalités ML restent à compléter. Certains tests échouent tant que les TODO ne sont pas résolus.
